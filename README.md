# AI Pocket Assistant

A minimalist Android application that turns an older Android device into a dedicated, pocket-sized AI voice assistant.

## Features
- **Hold-to-Talk Interface**: A simple, distraction-free voice UI.
- **Desktop Gadget Design**: Integrated clock and weather widget.
- **Configurable AI**: Powered by Gemini API, fully configurable in settings.
- **Offline Resilient**: App degrades gracefully when offline.
- **Lightweight**: Built with clean architecture and Jetpack Compose, optimized for minimal resource usage.
