# Setup Guide

## Building the Project
1. Open the project folder (`DeskApp`) in Android Studio.
2. Wait for Gradle sync to complete.
3. Build the project using `Build > Make Project` or by running `./gradlew assembleDebug` in the terminal.

## Running on a Device
1. Connect an Android device (Android 7.0 / API 24 or higher recommended).
2. Click "Run" in Android Studio to install the APK.

## First Run Configuration
1. When the app launches, grant the required Microphone and Location permissions.
2. Tap the Settings icon (⚙) in the top right corner.
3. Enter your **Gemini API Key**.
4. (Optional) Adjust the System Prompt for different assistant behaviors.
5. Tap **Save** and use the back arrow to return to the main screen.
6. Press and hold the **Mic icon** to talk to the AI Pocket Assistant.
